# Tamithm

这是一个由纯c编写的终端下落式音乐游戏，目前只有4K模式可以游玩

## 使用
终端运行run.exe即可，进入游戏标题页面 **按下任意按键** 进入游戏，按esc可以返回上一页面，在标题页面按esc可退出

## 谱面兼容性
| 音乐游戏 | 状态 | 说明 |
|------|------|------|
| Osu! | ✅ | mania模式4k谱面 |

## 功能实现
| 功能 | 状态 | 说明 |
|------|------|------|
| OSU!谱面难度算法还原 | ✅ | 由Gemini生成... |
| 过场动画 | ✅ | 对全角字符(中日文字符)会有抖动问题 |
| 游玩结算 | ✅ | 游玩成绩暂不可保存 |
| 多种音效 | ➡️ | 打击音效已完成 |
| 难度星级颜色提示 | ➡️ | 正在实现 |
| 延迟调整 | ➡️ | 正在实现 |
| 上隐 | ➡️ | 正在实现 |
| Autoplay | ❌ | 咕咕咕 |

## 编译
项目主目录执行
```
cd .\Tamithm
gcc -g .\*.c .\scenes\*.c .\data\*.c -o .\run.exe
```
